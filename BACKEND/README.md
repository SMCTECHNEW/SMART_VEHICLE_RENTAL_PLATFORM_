# Smart Vehicle Rental Platform Backend

## Start

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

## API Documentation

Open:

http://127.0.0.1:8000/docs

## Main API Modules

- Authentication
- Users
- Admins
- Vehicles
- Vehicle Categories
- Bookings
- Payments
- Pickup and Return
- Reviews
- Contact Messages
- Vehicle Health Scores
- Maintenance
- Discounts
